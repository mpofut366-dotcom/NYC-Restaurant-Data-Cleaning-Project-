# NYC-Restaurant-Data-Cleaning-Project-

# PROJECT OVERVIEW 
This dataset was utilised for the sole purpose of writing SQL queries to clean the NYC health inspection dataset 

# AIM 
The overall aim of the project was to clean and standardise the dataset so it is more suitable and ready for data analysis 

# METHODOLOGY 

- Handled missing values/ blank values (grades, scores, inspection dates & record dates).
- Removed columns not needed for analysis.
- Handled placeholder records (restaurants dated 01/01/1900 were restaurants not yet inspected).
- Changed date formats and assigned correct data types.
- Standardised categorical fields ( mapped older violation codes to the new/ standard codes and also standardised descriptions where the underlying violation was the same/had minor punctuation differences).
- Removed duplicate records (Microsoft Excel).
- Split inspection type column into inspection stage and inspection program. 

##### DATASET

The dataset was provided through Analyst Builder's Restaurant Health Inspection Analysis - NYC project.
The original dataset is not included in this repository due to file size.
